# Kapalı test pilotu — sayılar ve sunum

Şirket ve yatırımcıdan önce bu tablo dolsun. Hedef pencere: kapalı testin ilk 2–6 haftası.

## Hedef

| Metrik | Hedef | Şimdi |
|--------|------:|------:|
| Test kullanıcısı (opt-in) | 15 | |
| Aktif kullanıcı (en az 1 görev açan) | 30 | |
| İlan açan işletme | 10 | |
| Başvuru | 30 | |
| Tamamlanan görev (kupon veya teslim) | 5 | |

“Şimdi” sütununu her hafta elle doldur. Uydurma sayı sunuma girmez.

## İşletmeye söyleyeceğin teklif

3 ay ücretsiz ilan. Karşılık: mekanında 1 görev, logo kullanım izni, “Passla’da denedik” cümlesi. Nakit sponsor bu turda değil.

İlk kapılar: kafe, kuaför, spor salonu, restoran, yerel ajans.

## Sunumda değişecek 4 slayt

Mevcut sunumun sonuna veya “çekiş” bölümüne ekle. Kod slaytı ekleme.

1. **Problem** — işletme nakit yerine kendi hizmetini veriyor; kullanıcı görev karşılığı kupon alıyor.
2. **Ürün** — gerçek telefon ekranı: ana sayfa, görev, mesaj, kupon. Expo Go görüntüsü koyma.
3. **Kanıt** — yukarıdaki tablo. Boşsa “kapalı test başladı, tarih: …” yaz; rakam uydurma.
4. **Neden şimdi** — Play kapalı test sürümü 1.0.2 (9) yayında; üretim, 12 test kullanıcısı 14 gün kaldıktan sonra.

Sorulursa:

- Kim ödüyor? İşletme, ilan hakkı için. Kapalı testte ücret yok.
- Para nasıl kesilir? Karar: `BILLING_KARAR.md` — uygulama içi satış yok, işletme faturası web’den.
- Kullanıcı neden döner? Kuponu mekânda kullanmak için.
